日常启动：Safari → 分享 → 添加到主屏幕；以后点 DeskCam 即可自动连接（电脑须已运行且 IP 未变）。相机授权由 iOS 管理，主屏幕入口可能每次询问；可在 Safari 的此网站设置中将相机设为“允许”。若主屏幕提示未配对，可先继续用 Safari 书签，或在主屏幕内完成一次配对。

相机权限与支架使用

如每次都问相机权限：用 Safari 打开相同地址 → 页面菜单 → 更多 → 此网站设置 → 相机 → 允许。主屏幕 Web App 可能不继承此设置；仍反复询问时，可重新添加到主屏幕并关闭“作为网页 App 打开”，或使用 Safari 书签。授权不能由 DeskCam 自动绕过。遮罩、停止/开始、画质、倍率和调焦都可在电脑控制；系统相机拍照需要在手机点按确认。
