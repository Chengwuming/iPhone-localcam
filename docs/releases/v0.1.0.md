# LocalCam v0.1.0

首个可安装版本。

## 包含内容

- iPhone Safari 通过本地 HTTPS/WSS 向 Windows 发送摄像头画面。
- Windows 原生预览、画面控制、托盘运行和开机启动选项。
- 可供相机、OBS 和会议软件选择的 `LocalCam Camera` 虚拟摄像头。
- 一次性二维码配对、本地 CA、局域网和热点地址选择。
- 设置页手动检查 GitHub 最新正式版本。
- Windows 11 x64 自包含安装包；无需另装 .NET 运行时。

## 下载

下载 `LocalCam-Setup-x64.exe`。安装与虚拟摄像头注册需要管理员权限。

SHA-256：`E3E064C0F2740C889DDAC9448B2C89DA516D1A41ECAACE692BB973EE8D79C553`

安装包尚未进行商业代码签名，Windows 可能显示未知发布者提示。

## 已知限制

- 当前使用 JPEG/WSS，不是 WebRTC/H.264。
- 虚拟摄像头固定输出 640×480 NV12。
- 尚未完成所有会议软件、多应用并发和长期运行测试。
- 不包含音频、录像或滤镜。
